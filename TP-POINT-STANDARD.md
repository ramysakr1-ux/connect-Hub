# The Connect standard for a TP point

Agreed with Ramy on 26 Oct 2026 (TP 6: "TP6 thing as main aim and just like some watch out for that's all"). Every set in the TP point library, and every set offered to the Pool, follows it, so a trainee meets the same fade whoever wrote the set. The set editor (`28_tp_point_sets.html`, `standardIssues()`) flags any lesson that breaks it, and the import ("Start from your TP point") brings in whatever the point holds.

## The fade

| | TP 1–2 · Full | TP 3–4 · Guided | TP 5 · Outline | TP 6 · Bare |
|---|---|---|---|---|
| Main aim | In full: "By the end of the lesson, students will have…" | One word: the lesson type, shown as their focus | One word | One word |
| Sub aim | In full: "To…" | TP 3 one word; TP 4 the trainee's own | One word | The trainee's own |
| Lesson shape | Named, as the trainee's plan names it | Not given | Not given | Not given |
| Stages | Named, each with **its stage aim** ("To…", one short line), its time and its interaction | Named, no times, no interaction | Named only | None |
| Under each stage | The instructions: short imperative bullets | One short line: which exercise, and what it is for | Nothing | — |
| Watch out for | Where it helps | One line where it matters | No | **Yes: a few lines, and that is all they get beside the aim and the pages** |
| Context, pages, exercises, audio | Yes | Yes | Yes | Yes |

## Also true at every level

- **Stage aims at TP 1–2 are the example.** One short line under the stage name, starting "To…": the form the trainee writes under "What this stage is for" in their own plan. Example: Lead-in: *To get students interested in the topic and the photo.*
- **A trainee's first lesson at a new level may be written one level up** (Ramy, 12 Oct 2026).
- **Making their own material is allowed at any TP**, never a requirement tied to a TP number.
- **The sub aim is a different family from the main aim** (receptive, productive, language).
- **Imperative, short, not wordy, little jargon.** Page and exercise numbers right.
- **The prioritization rule.** In a language lesson built on a text, the text stages are short; the language work carries the time.
- **Nothing copied from a teacher's book.** Name the pages; write your own lesson.
- **American spelling** in everything Connect writes. Quotations from the book stay as printed.

## Sessions and TPs

Sessions pair into TPs: 1A/1B = TP 1 … 6A/6B = TP 6. The level is set per session (`scaffold`: `full`, `guided`, `outline`, `bare`), and the editor defaults it by TP number.
