Useful sets, freely taken.

The Pool is an open library. Connect’s own sets come free with Lite. Anyone can browse and take an approved set; giving is optional and earns credit only.

FROM SET TO LEARNING RECORD

One point, one clear chain.

The set gives a course a common teaching procedure. Rotation makes it a real point in time. The live record keeps the learning work, evidence and feedback connected without confusing one with another.

1
Pool or own setProvides a versioned procedure, book context and lesson sequence.
2
Course set copyThe centre adds local links, pages and material availability without changing the source set.
3
Rotation and timetableGive the point its trainees, group, day and true teaching duration.
4
Trainee plan → teach → reflectCreates the trainee’s own work and becomes the base for tutor feedback.
5
Feedback and trackerReferences the particular TP point, not a vague or separate status screen.
Important separationA TP set is a reusable procedure. A TP record is evidence from one actual teaching point. Updating one must not silently rewrite the other.

What a trainee sees

A trainee does not need the whole operating map in order to be prepared.
