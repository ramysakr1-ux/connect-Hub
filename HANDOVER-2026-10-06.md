## First job on the Mac: bring the store into the repo with clasp

Do this before any other store work. Ramy has two one-time steps; the rest is
yours.

1. **Ramy, once:** turn on the Apps Script API at
   <https://script.google.com/home/usersettings>.
2. Install clasp: `npm i -g @google/clasp`.
3. **Ramy, once:** `clasp login` opens Google's sign-in in his browser; he
   clicks through. The token lands in `~/.clasprc.json` (gitignored here as a
   precaution; it must never be committed).
4. `store/gas/.clasp.json` is already written with the script id. From
   `store/gas/`, run `clasp pull`. It writes `Code.js` (clasp's name for
   `Code.gs`) and `appsscript.json`. **Commit that pull untouched as the
   baseline** — it is the exact code that is deployed (v73), and nothing in
   this repo has had that before.
5. Check `clasp deployments` and find the web app deployment. Its id is the
   long `AKfycb…` string in the store URL in `hub-store.js`
   (`AKfycbz5ESCtTg6kIDNCf7ynt1fB0tOSVusgOUiMub9-wEZunwQ2uTw2wzz1vmbHxzbvpG-eyA`).
   Every deploy from now on is
   `clasp push` then `clasp deploy -i <that id> -d "v74 …"`. That is the pencil
   → New version → Deploy, done from the terminal. **A bare `clasp deploy`
   with no `-i` makes a new deployment with a new URL. Never.**
6. Also: `node --check store/gas/Code.js` passes on this code (it is plain
   JS). Run it before every push.

## Lessons the walker and the day taught

- A python edit script with several edits aborts on the first failed
  assertion and silently drops the rest. One edit per script.
- Author `display:block` beats the UA's `[hidden]`; hence the `!important`.
- The dictionary bar on phones covers anything at the bottom of the page;
  `hubReserveForBar` adds its height.
- Course admin's `#tutors` door needs a second scroll after the data lands.
- The walker (`walk-with-data.mjs`) takes `ONLY=regex`, `VIEW=1|top`,
  `SHOTS=1` (writes `_walk-shots/`), `PORT`, `DOORS=1`.
