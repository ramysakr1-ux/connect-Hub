2 · The six shapes

Six lesson shapes. Before you look: in pairs, write the stages of each one, in order, as far as you know them. Then reveal.

PPP

  1. Lead-in
  2. Present (meaning, form, pron.)
  3. Practice (accuracy)
  4. Production (fluency)
  5. Error correction

Test-Teach-Test

  1. Lead-in
  2. First test (diagnostic)
  3. Teach (clarify gaps)
  4. Second test
  5. Feedback

Text-Based

  1. Lead-in / build context
  2. Reading or listening task
  3. Highlight target language
  4. Clarify TL
  5. Practice
  6. Feedback

Language Practice

  1. Lead-in (optional)
  2. Set up
  3. Controlled practice
  4. Freer practice
  5. Feedback

Receptive Skills

  1. Lead-in
  2. (Prediction task)
  3. Pre-teach vocab
  4. Gist, then detail, then specific information
  5. Post-task response

Productive Skills

  1. Lead-in
  2. Preparing to write/speak
  3. Useful language (optional)
  4. Speaking/writing task
  5. Feedback

8 · Pacing: budget the minutes

You have 45 minutes for a Text-Based lesson. Budget the minutes across the three stages below; the total should land on 45.

Total: 0 / 45 min

If your Lead-in & Text Reading stage runs 5 minutes over, which stage do you trim without destroying the lesson aim?

Trim Controlled Practice & Feedback, not Clarification. The clarification stage (meaning, form, pronunciation) is where the learning happens; cutting it short undermines the lesson aim. Practice can be shortened to one activity instead of two, or feedback can be done more briefly, without losing the core teaching point.
StageTarget allocation (45-min TP)
Lead-in & Text Reading (Gist/Detail)10–12 mins
Clarification (MFPA)15 mins
