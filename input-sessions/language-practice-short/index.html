Input session · CELTA

Language practice: from controlled to free

72 minutesThe longer session

Drilling gets the form right with no real message. This session is about what comes after: three stages of practice activity that gradually hand control from teacher to learner, ending in a loop task that runs all three stages back to back on the same structure.

Lead-in 5 minutes

A learner can drill “Why don’t we go for coffee?” perfectly. Does that mean they can actually use it, to suggest something real, to someone real, when they mean it? That gap is what this session is about.

The three stages, one target structure each way 25 minutes

Same language throughout: offering and suggesting. Click each stage to see it worked, then try it yourselves.

Sort the activity by stage 8 minutes

Each activity below could be run at one of the three stages. Pick which.

More worked examples, same three stages 8 minutes

A second target structure (“going to”: future plans), so the framework generalizes rather than sticking to one example. Click to reveal.

Loop task: do all three stages back to back 12 minutes

One target structure (“used to”: past habits), one quick task per stage, three to four minutes each. Click a loop to see it and run it live before moving to the next.

Spot the mismatch 6 minutes

A trainee labels their pairwork activity “free practice” because learners are talking in pairs, but every learner must complete the sentence frame “If I were you, I’d ___.” What’s the actual stage, and why does “pairs” not decide it?

Design your own 5 minutes

In pairs: take the target language “wish + past simple” (present regrets). Design one activity for each stage (controlled, semi-controlled, free) in one minute each. Share one with the room.

Wrap-up 3 minutes

A lesson doesn’t need all three stages every time, but if you only ever drill and never free-practice, learners can produce a form on command and still never use it when it matters.
